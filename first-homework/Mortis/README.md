# Week1 绿球识别与运动追踪
**Mortis**

## 1. 概述

程序从视频中逐帧检测绿色小球，并完成：

1. 用圆形框标出小球位置（含半径，即大小）；
2. 用箭头表示小球运动方向；
3. 用箭头长度 + 速度文本反映速度大小与加减速变化；
4. 短时遮挡（如贴边被裁切）时用速度外推，避免跟踪中断。

## 4. 构建与运行

在仓库根目录执行：

```bash
cmake -S first-homework/Mortis -B first-homework/Mortis/build
cmake --build first-homework/Mortis/build -j
```

编译产物为 `first-homework/Mortis/build/ball_tracker`。

运行（使用默认输入/输出路径）：

```bash
./first-homework/Mortis/build/ball_tracker
```

默认输入视频 `first-homework/first-homework.mp4`，输出标注视频 `first-homework/Mortis/first-homework-annotated.mp4`。

也可指定输入/输出：

```bash
./first-homework/Mortis/build/ball_tracker 输入视频.mp4 输出视频.mp4
```

## 5. 实现方案

每帧依次执行 5 步：

1. **绿色分割**：BGR 转 HSV，`inRange(35,45,40 ~ 95,255,255)` 提取绿色区域，再做开运算（去噪点）+ 闭运算（填空洞）。
2. **候选筛选**：`findContours` 找轮廓，按面积、圆度（`4πA/P²`）、长宽比（w/h）过滤，区分绿球（圆）与绿色圆柱（细长）；贴边时放宽阈值，避免球被裁切后漏检。
3. **跨帧匹配**：对每个候选算形状分（圆度 + 长宽比 + 面积加权），再用上一帧「中心 + 速度」预测当前位置，距离或半径突变过大的候选直接拒绝，抑制目标在球与圆柱之间跳变。
4. **遮挡外推**：连续丢失 < 8 帧时，用上一帧速度外推位置（标注 `predicted`）；超过则重置状态。
5. **可视化**：绘制检测圆、圆心、速度箭头（方向=速度矢量，长度∝速度），以及速度/加减速状态文本，逐帧写入输出视频。

## 6. 关键问题与处理

### 6.1 绿色圆柱干扰

画面中同时存在绿色圆柱，仅靠颜色会误检。通过圆度 + 长宽比过滤，并在匹配阶段加入距离/半径约束，避免目标跳变。

### 6.2 小球贴边被裁切

球靠近画面边缘时轮廓变形，严格阈值会漏检。对贴边目标放宽几何阈值，并放宽面积上限。

### 6.3 速度显示不稳定

目标误匹配会导致速度突变。通过跨帧距离约束与半径约束拒绝不合理候选。

### 6.4 短时遮挡速度归零

球被短暂遮挡时检测不到轮廓。丢失帧数未超阈值时用匀速外推，持续输出合理位置与速度。

## 7. 关键参数表

| 参数 | 值 | 位置（main.cpp） | 作用 |
|------|-----|-----------------|------|
| 绿色 HSV 下界 | (35, 45, 40) | `kLowerGreen` | 绿色检测范围 |
| 绿色 HSV 上界 | (95, 255, 255) | `kUpperGreen` | 绿色检测范围 |
| 轮廓面积范围 | 7000 ~ 32000 | `kMinArea` / `kMaxArea` | 噪声与超大色块过滤（随分辨率调） |
| 圆度阈值 | 0.68（贴边 0.45） | `kMinCircularity` | 球/圆柱区分关键 |
| 长宽比范围 | 0.85 ~ 1.20（贴边 0.55 ~ 1.45） | `kMinAspect` / `kMaxAspect` | 球/圆柱区分 |
| 最大丢失帧数 | 8 | `kMaxLostFrames` | 遮挡外推时长 |
| 箭头缩放 | 4.5 | `kArrowScale` | 速度 → 箭头长度 |
| 箭头长度范围 | 25 ~ 140 | `kArrowMinLen` / `kArrowMaxLen` | 避免观感失衡 |

> 面积阈值 7000~32000 是针对当前视频分辨率（球体较大）调出来的，换视频需重新调整。

## 8. 局限与后续改进

- 单目标假设：只追踪一个绿球，不支持多球。
- 颜色硬编码：光照变化大时 HSV 阈值可能失效。
- 可进一步引入卡尔曼滤波（替代当前匀速外推）、自适应颜色阈值、多目标匹配（匈牙利算法）。
